# 🐟 Sindicato de Pesca

- **ideia inicial:** Existe uma certa dificuldade para os pescadores saberem todas as informações relacionadas a pesca, o que faz com que o incentivo para entrar na área, por isso escolhemos fazer um site para resolver esse problema
---

## 🐠 Temporadas de Pesca:
-  Não existe um lugar que fala tão claramente sobre os momentos do ano em que a pesca é permitida e os que não, por isso iremos dar todos os detalhes sobre as temporadas de pesca.

## 📝 Informações Sobre os Peixes
-  tambêm é necessário que os pescadores tenham informações claras sobre quais peixes vivem em quais regiões, qual é o melhor tipo de isca para cada peixe, tamanho e peso dos peixes, entre outras informações. Nosso intuito é ter uma área onde os próprios pescadores possam compartilhar suas informações e conhecimentos sobre os tipos de peixes

## 🎯 Campeonatos
-  É importantíssimo que os pescadores tenham informações sobre o funcionamento das competições e possam participar delas, por conta disso faremos uma aba que reunirá todos os torneios da região, com suas regras, local de realização, onde fazer a inscrição, entre outras informações
